# External-engine benchmark / آزمون با موتور خارجی

**Research only. No funded account, wallet, signing or 24/7 trading service.**
This additive experiment uses `backtesting.py==0.6.6`, not the old Arz engine. See the paired report under `docs/en/upstream_benchmark_20261016.md` or `docs/fa/upstream_benchmark_20261016.md`.

## Read every recorded outcome without dependencies or network

From repository root, using a new output filename:

```bash
python3 experiments/upstream_benchmark/unpack_results.py --output all-outcomes.csv
```

This reconstructs all1,056 registered cases:480 completed and576 explicit data/warmup skips. Eight-decimal metric summaries are a storage representation, not independent replications. Original full CSV hash is published; complete ledgers/precision CSV are regenerated by the engine below with matching entitled inputs.

## Isolated offline software tests

```bash
python3 -m venv .venv-upstream
.venv-upstream/bin/python -m pip --isolated install --only-binary=:all: --index-url https://pypi.org/simple -r experiments/upstream_benchmark/requirements.lock
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=experiments/upstream_benchmark .venv-upstream/bin/python -m unittest discover -s experiments/upstream_benchmark -p 'test_*.py' -v
```

Dependencies are exact version pins, not a complete supply-chain audit or hash-locked trust proof. The study used Python3.10.12; legacy Arz's full suite retains its own supported Python requirement. No system installation is needed.

## Reproduce historical sensitivity study

Obtain permitted data and compare SHA256 to `reports/upstream_benchmark_20261016/data_provenance.json`. Optional bounded reproduction helper (requires explicit network flag and a new directory):

```bash
python3 experiments/upstream_benchmark/fetch_data.py --download --output runtime/new_dex_data
PYTHONPATH=experiments/upstream_benchmark .venv-upstream/bin/python experiments/upstream_benchmark/benchmark.py --output runtime/new-upstream-results
```

The downloader makes no request without `--download`; it stops on failure, does not rotate endpoints and does not fetch the previously denied older-history range. Do not overwrite retained data to obtain a better result. If data/provider rights or access are missing, stop that acquisition and keep the reported limitation. A hash mismatch means it is a different dataset and not exact reproduction.

The historical study is not a strategy optimizer. Every fixed rule/cost/window is run or explicitly skipped; old code and market results are not altered. Fee assumptions remain uncalibrated. A second positive annual window overlapping the first is not an independent year.
