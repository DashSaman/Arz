## قواعد تحویل هر مرحله

برای هر تغییر بعدی باید پیش از تغییر وضعیت، فهرست شواهد، مسیر فایل‌ها، SHA یا Hash، دستور اجرا، Exit Code، CI واقعی، یافته‌های مثبت و منفی، تغییر سرمایه فرضی، و حدود علمی گزارش شود. **UNKNOWN هرگز صفر نیست.** اگر داده نرسد، وضعیت BLOCKED با علت ثبت شود. وضعیت Task فقط پس از عبور از Exit Gate عوض شود؛ اصل شاهد قبلی حذف یا با بازنویسی خاموش جایگزین نشود.

کنترل آفلاین:

```bash
PYTHONPATH=src:. python scripts/verify_research_control.py
PYTHONPATH=src:. python -m unittest discover -s tests -p 'test_verify_research_control.py' -v
```

این کنترل **فقط سازگاری محلی گزارش** را بررسی می‌کند؛ صحت محتوا یا جدیدبودن PRهای GitHub باید جداگانه بررسی شود. بدون نیاز به شبکه، کلید خصوصی یا اجرای معامله است.

**کار بعدی: WAL-01** — با سندهای موجود، مبنای خرید و مسیر اقتصادی همان تراکنش Mitch را تکمیل کن. مراحل OPS-01 و OPS-02 به‌صورت مستقل و امن در main ثبت شده‌اند. برای نتایج و لینک‌های مرجع از فایل JSON استفاده کن، نه حافظه چت. خرید و فروش واقعی همچنان غیرفعال است.
