## چه چیزی را نمی‌توان از این داده نتیجه گرفت؟

- شش کندل یک روز، یک بک‌تست ۱۲ماهه نیستند؛ برای S0 دست‌کم ۱۹۴ کندل Warmup هم لازم است. فقط **پنج کندل** هر بازار هنگام اولین دریافت واقعاً کامل بودند.
- Trading Strategy API کندل‌های بدون معامله را الزاماً تولید نمی‌کند؛ نبود کندل معادل قیمت ثابت یا سود صفر نیست. همچنین در این پایلوت هنوز نسبت شناسه Pair ID ارائه‌دهنده با قراردادهای Pool/Token روی زنجیره **مستقل دوباره احراز نشده** است.
- QuoterV2 از روی وضعیت یک بلاک مقدار خروجی و تخمین Gas **برحسب واحد** را بازمی‌گرداند؛ Gas Estimate هزینه پرداخت‌شده به دلار نیست. Gas L1/L2، رسید تراکنش، میزان لغزش تا ثبت، مسیر جایگزین، MEV و کارمزد تراکنش شکست‌خورده هنوز مشاهده نشده‌اند.
- `eth_call` **معامله نیست**؛ این قیمت از سیگنال ۶۰ثانیه‌قبل یک استراتژی بازسازی نشده و سود تحقق‌یافته‌ای ثبت نشده است. برای cbBTC مقدار خروجی باید با ۸ رقم اعشار و WETH با ۱۸ رقم تفسیر شود.
- کل ورودی به‌عنوان `ONE_DAY_PRE_FROZEN_OOS_DIAGNOSTIC_NOT_FINANCIAL_BACKTEST` ثبت شد، نه شواهد بازده واقعی. این داده برای انتخاب یا تغییر پارامترهای ATR/S0 استفاده نشده است.
