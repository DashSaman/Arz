# Arz V5 — داشبورد محلی جمع‌آوری داده

این یک گزارش وضعیت محلی HTML و JSON است که از فایل‌های Collector مستقل PR82 ساخته می‌شود. هیچ درخواستی به شبکه نمی‌فرستد، کیف‌پول یا سفارش ندارد و سودی محاسبه یا تأیید نمی‌کند.

روی میزبان مجاز، از ریشه ریپو اجرا کنید:

~~~sh
mkdir -p runtime/arz-collector/monitor
PYTHONPATH=src:. python scripts/strat01_local_monitor.py \
  --data-root runtime/arz-collector \
  --html runtime/arz-collector/monitor/index.html \
  --json runtime/arz-collector/monitor/status.json
~~~

فایل runtime/arz-collector/monitor/index.html را با مرورگر محلی باز کنید. این صفحه JavaScript و منبع خارجی ندارد و تا زمان اجرای دوباره دستور به‌روز نمی‌شود. داده اصلی بازار و رویدادهای ثبت‌شده بازنویسی نمی‌شوند و خروجی مانیتور اجازه جایگزین‌کردن آن‌ها را ندارد.

در صفحه می‌بینید: تعداد فایل معتبر، جفت‌ کندل‌های مشاهده‌شده WETH و cbBTC، زمان ثبت هر دو منبع تا یک ساعت پس از بسته‌شدن، بیشترین توالی معتبر نسبت به معیار ۱۹۴ کندل، شش نوبت UTC اخیر، آخرین خطای اجرایی و Heartbeat. اگر منبع خراب باشد، وضعیت SOURCE_FAIL_CLOSED نشان داده می‌شود.

**این داشبورد اثبات سود، دریافت داده در زمان انتشار اصلی، اجرای معامله واقعی یا تأیید Paper Trading نیست.** مانیتور هنوز یک Snapshot محلی است، نه سرویس وب خودکار یا اجرای روی سرور مستقل. وضعیت سرمایه واقعی NO-GO و صفر دلار است.
