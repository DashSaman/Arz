# گزارش مأموریت ۰۴ Arz — زیرساخت Paper Trading مستقل (۱۸ آبان ۱۴۰۵ / ۸ نوامبر ۲۰۲۶)

## وضعیت واقعی شروع

آخرین `main` در آغاز مأموریت: `11e8bf28dee8ff85d386187928e53ead2b032144`. تغییرات در شاخهٔ `parallel/20261108-paper-infrastructure` توسعه یافته‌اند و برای بازبینی PR مستقل خواهند داشت.

در `main` قبلاً Collector با ساعت مستقل UTC، کانتینر غیرریشه و فقط‌خواندنی، heartbeat، آرشیو و بازیابی شواهد و داشبورد ایستای آفلاین وجود داشت. دستور قدیمی `arz paper` محدود و مخصوص WETH بود؛ اجرای ۲۴ساعتهٔ حساب مشترک WETH/cbBTC اثبات نشده بود. داده‌های Collector قیمت اجرایی تأییدشده نیستند؛ هزینهٔ کامل `COST_UNVERIFIED` باقی مانده است. **نتیجهٔ مالی NO-GO، سرمایهٔ واقعی صفر، معاملهٔ واقعی غیرفعال و روزهای Paper واجد شرایط صفر است.**

## آنچه پیاده‌سازی شده

- `scripts/strat01_multi_paper.py`: دفتر فرضی با یک حساب مشترک حداکثر ۱۰۰ USDC، دو موقعیت مستقل WETH و cbBTC، ورود و خروج Long/Flat، هزینهٔ هر سمت، لغزش، گس، ماندهٔ نقدی، ارزش روز حساب، سود/زیان بسته‌شده و بازده خالص روزانهٔ شبیه‌سازی‌شده. سقف سفارش ۲۵ دلار، سفارش هدف ۲۰ دلار، ذخیرهٔ نقد ۱۰ دلار، سقف چهار ورود و هزینهٔ روزانه ۲ دلار، حد افت کل ۱۰٪ و زیان روزانه ۳٪ رعایت می‌شود؛ این حدود تضمین محدودماندن ضرر نیستند. خروج‌ها قبل از ورودها پردازش می‌شوند و فروش جزئی بهای تمام‌شده را حفظ می‌کند.
- `scripts/strat01_paper_runtime.py`: پایش مستقل هر چهار ساعت با تأخیر ۱۵ دقیقه از بسته‌شدن کندل؛ خواندن آرشیو Collector صرفاً از مسیر فقط‌خواندنی؛ اعتبارسنجی ۱۹۴ کندل متوالی برای هر دو بازار؛ سیگنال ثابت و صرفاً پژوهشی `trend` برای دو دارایی؛ ثبت وضعیت و رویداد بدون بازسازی مصنوعی وقایع گذشته؛ جلوگیری از ثبت دوباره و بازپخش کامل دفتر هنگام راه‌اندازی مجدد. سیگنال این نسخه ادعای بهترین یا سودده‌ترین استراتژی نیست.
- `scripts/strat01_paper_backup.py`: خروجی ZIP از داده‌های تغییرناپذیر دفتر، مشاهدات و هشدارهای محلی، همراه با هش SHA-256 و بازیابی صرفاً در پوشهٔ تازه پس از بازپخش و صحت‌سنجی. heartbeat، عملکرد واقعی ۹۰روزه و وضعیت سرویس از پشتیبان بازتولید نمی‌شوند.
- `scripts/strat01_paper_sbom.py`: صورت‌موجودی SPDX 2.3 برای فایل‌های بسته‌بندی‌شده و پکیج‌های واقعاً نصب‌شده در تصویر Docker. **این گزارش به‌تنهایی اسکن آسیب‌پذیری نیست.**
- `deploy/paper/`: فایل Docker با تصویر پایهٔ ثابت، بدون نصب وابستگی در زمان ساخت، شبکهٔ قطع، کاربر UID 65534، ریشهٔ فقط‌خواندنی، حذف Capabilityها، `no-new-privileges`، محدودیت منابع، Health Check، Restart و خروجی‌های ماندگار.
- `.github/workflows/strat01-paper-infrastructure.yml`: تست واحد، بازپخش، بازیابی، بررسی کنترل تحقیقات، ساخت واقعی Docker، آزمون آفلاینِ بدون معامله، اعتبارسنجی هش سورس و صورت‌موجودی کانتینر.

موتور جدید به‌عمد در پوشهٔ `scripts/` قرار دارد تا اثرانگشت موتور قدیمی `src/arz` و هویت دفترهای Paper قبلی ناخواسته تغییر نکند.

## مرزبندی امنیت و سوددهی

در حالت پیش‌فرض هیچ قرارداد هزینه‌ای تأیید نشده و متغیر `ARZ_PAPER_APPROVED_COST_SHA256` خالی است. دریافت کندل، مشاهدهٔ یک قیمت، خروجی Backtest یا تخمین Quoter **برای ایجاد Fill کافی نیست**. اگر بعدها تیم مستقل مدل هزینه را با شواهد معتبر تأیید کند، ورودی جداگانهٔ قیمت لحظهٔ دنبال‌کننده باید دارای هش قرارداد بررسی‌شده، زمان معتبر حداکثر ۶۰ ثانیه‌ای، هویت دو بازار و اطلاعات نقدشوندگی قبلی برحسب USDC باشد. مقدار ساختگی SHA مدرک صحت اقتصادی محسوب نمی‌شود.

حتی Fill حاصل از ورودی‌های مورد تأیید، **صرفاً فرضی و بدون تسویهٔ بلاک‌چینی** خواهد بود. این سرویس Wallet، کلید خصوصی، امضا، Broadcast یا شبکه ندارد. تعداد روزهای Paper واجد شرایط تا ارزیابی مستقل صفر می‌ماند. خطای داده، گپ، تغییر نسخهٔ الگوریتم/پایتون، اختلاف دفتر، خرابی فایل، تأخیر یا نقض ریسک نباید با پاک‌سازی خودکار یا ساخت معاملهٔ عقب‌افتاده پنهان شود.

## دستورهای آزمون و استقرار محدود

در مخزن بازبینی‌شده:

```sh
PYTHONPATH=src:. python3 scripts/verify_research_control.py
PYTHONPATH=src:. python3 -m unittest discover -s tests -p 'test_strat01_multi_paper.py' -v
PYTHONPATH=src:. python3 -m unittest discover -s tests -p 'test_strat01_paper_*.py' -v
docker build -f deploy/paper/Dockerfile -t arz-paper:reviewed .
docker image inspect --format '{{.Id}}' arz-paper:reviewed
```

**استقرار روی سرور شخصی هنوز انجام نشده و نیازمند تأیید جداگانه است.** پس از تأیید، پوشه‌های `journal`، `observations` و `alerts` زیر پوشهٔ مستقل `arz-paper` باید برای UID 65534 قابل‌نوشتن باشند. پوشهٔ Collector تنها خواندنی، و پوشهٔ ورودی دادهٔ دنبال‌کننده نیز تنها خواندنی متصل می‌شود.

```sh
export ARZ_COLLECTOR_DATA_ROOT=/ABSOLUTE/PATH/arz-collector
export ARZ_PAPER_DATA_ROOT=/ABSOLUTE/PATH/arz-paper
export ARZ_PAPER_INPUT_ROOT=/ABSOLUTE/PATH/arz-paper-input
sudo install -d -o 65534 -g 65534 -m 700 "$ARZ_PAPER_DATA_ROOT"
for folder in journal observations alerts; do
  sudo install -d -o 65534 -g 65534 -m 700 "$ARZ_PAPER_DATA_ROOT/$folder"
done
sudo install -d -m 750 "$ARZ_PAPER_INPUT_ROOT"
export ARZ_PAPER_IMAGE="$(docker image inspect --format '{{.Id}}' arz-paper:reviewed)"
unset ARZ_PAPER_APPROVED_COST_SHA256
docker compose -f deploy/paper/docker-compose.yml config --quiet
# اجرای دستور بعدی فقط روی میزبان تأییدشده:
docker compose -f deploy/paper/docker-compose.yml up -d
```

گزارش‌ها در `status.json` و `status.html` هستند؛ این فایل‌ها **داشبورد اینترنتی عمومی** نیستند. پوشهٔ `alerts` برای قطعی Collector، نبود جفت‌دادهٔ فعلی و توقف ریسک هشدار **محلی** ثبت می‌کند و ارسال Telegram/Email یا تحویل Paging را ثابت نمی‌کند. SIGTERM توقف کنترل‌شدهٔ فرایند را انجام می‌دهد و کندل جامانده را به گذشته نسبت نمی‌دهد. پایش خارجی و تست واقعی ارسال هشدار باید مستقل تکمیل شود.

## بازیابی و تست خرابی

پس از متوقف‌کردن کانتینر و بررسی عدم وجود قفل نویسنده:

```sh
PYTHONPATH=src:. python3 scripts/strat01_paper_backup.py backup \
  --paper-root "$ARZ_PAPER_DATA_ROOT" --archive /SAFE/OFFLINE/arz-paper-backup.zip
PYTHONPATH=src:. python3 scripts/strat01_paper_backup.py restore \
  --paper-root /NEW/EMPTY/arz-paper-restored --archive /SAFE/OFFLINE/arz-paper-backup.zip
```

قبل از ادعای آمادگی عملیاتی، آزمون واقعی قطعی شبکه، نبود یا خرابی منبع، تأخیر Clock، گپ کندل، ورودی تکراری و متناقض، قطع فرایند میان نوشتن دفتر و مشاهده، بکاپ و Restore در میزبان دوم، تمام‌شدن دیسک، بازیابی موقعیت باز، سازگاری نسخه، Rolling Back و تحویل هشدار باید مستند شود. آزمایش یک‌بارهٔ کانتینر یا CI معادل کارکرد ۹۰ روزه نیست.

**نتیجه:** یک زیرساخت آفلاین و قابل‌آزمون اضافه شده، اما مسیر کامل کسب شواهد قیمت اجرایی و هزینه، پوشش پیوستهٔ داده، استقرار میزبان مستقل و ۹۰ روز واقعی هنوز مانع‌اند. تا آن زمان `NO-GO` و سرمایهٔ واقعی **صفر** باقی می‌ماند.
