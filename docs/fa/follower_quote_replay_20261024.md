## کارهای انجام‌شده و تأییدشده

- ماژول `src/arz/multi_edge/follower_replay.py`: بررسی آفلاین جفت قیمت ورود/خروج دنبال‌کننده.
- اسکریپت `scripts/replay_follower_quotes.py`: خواندن JSON محلی، ثبت هش SHA-256 و آزمون تأخیرهای **۳، ۱۰، ۳۰، ۶۰ و ۱۲۰ ثانیه**.
- **۱۸ تست از ۱۸ تست محلی موفق**؛ فرمان: `PYTHONPATH=src:. python -m unittest discover -s tests -p 'test_*.py' -v`. تست‌ها **با داده مصنوعی** و روی محیط جدا شامل تست‌های جدید اجرا شدند. مجموعه ۲۲۵ تست قدیمی Phase A در این محیط مجدداً اجرا نشده است و موفقیت CI شاخه تا زمان مشاهده تأیید نمی‌شود.
- کامپایل فایل‌های جدید موفق بود. هش‌های گزارش، مربوط به فایل‌های آزمایش‌شدهٔ محلی‌اند و قبل از ادعای برابری با نسخه منتشرشده، باید با محتوای GitHub مطابقت داده شوند.
- در این مرحله هیچ RPC، API پولی، کیف‌پول، امضا، تأیید توکن، معامله یا اجرای سرویس انجام نشده است.

## قواعد سخت‌گیرانه

برای هر سیگنال، زمان تراکنش `chain_at`، زمان نهایی‌شدن `finalized_at` و **زمانی که ربات واقعاً از آن مطلع شده** `seen_at` مستقل هستند. قیمت ورودی فقط پس از `seen_at + delay` پذیرفته می‌شود؛ نه از قیمت تاریخی خرید نهنگ. قیمت باید هم اندازه سفارش واقعی و هم از نظر زمان معتبر باشد. ورودی و خروجی ناقص، کارمزد نامعلوم، قیمت قدیمی، تکرار و وابستگی سه خوشه کیف‌پول رد می‌شوند.

سه شناسه خوشه مستقل باید ارائه شود؛ اما این ابزار **هویت و مستقل‌بودن واقعی خوشه‌ها، نمره تاریخی کیف‌پول یا صحت قیمت‌ها را اثبات نمی‌کند**. هزینه استخر و Price Impact در قیمت گرفته‌شده منظور شده و دوباره کسر نمی‌شوند. دوبرابرکردن تنها هزینه شبکه **معادل آزمون تنش کامل اسلیپیج نیست**.

**این هنوز بک‌تست کامل H1 نیست.** زمان تصمیم خرید/فروش باید از موتور مجزا و بدون نگاه به آینده تهیه شود. خروج‌های اصلی H1 (فروش دو خوشه / استاپ ۳ ATR / توقف ۱۴ روزه)، حساب مشترک سرمایه، موجودی روزانه و معاملات هم‌پوشان در این ابزار شبیه‌سازی نشده‌اند. بنابراین جمع سود جفت‌قیمت‌ها بازده کل حساب نیست و اثبات رشد مرکب محسوب نمی‌شود.

## اجرای آفلاین

```bash
PYTHONPATH=src:. python -m unittest discover -s tests -p 'test_follower_replay.py'
PYTHONPATH=src:. python -m unittest discover -s tests -p 'test_replay_follower_runner.py'
PYTHONPATH=src:. python scripts/replay_follower_quotes.py --input tests/fixtures/follower_quote_synthetic.json
```

ورودی JSON دارای `schema_version=1`، `data_class` برابر `SYNTHETIC` یا `HISTORICAL_UNVERIFIED` و دو آرایه `episodes` و `quotes` است. هر قسمت ورود/خروج، زمان زنجیره/نهایی‌شدن/مشاهده و سه خوشه مستقل دارد؛ قیمت شامل زمان بازار/دریافت، مقدار دقیق ورود/خروج، کارمزد شبکه و وضعیت کارمزد مستتر است. کارمزد نامعلوم باید `null` باشد، نه صفر.

نمونه مصنوعی عمداً تنها در تأخیر ۶۰ ثانیه قابل جفت‌شدن است. این نتیجه **نمونه تست نرم‌افزار است نه داده بازار**. تعداد جفت‌های واقعی این مرحله: **صفر**.

## کارهای ضروری بعدی

۱. دریافت قانونی و کامل تاریخچه رسیدها و لاگ‌ها، کنترل بازه و ثبت هش، قیمت تاریخی و کارمزد واقعی، بدون دورزدن محدودیت RPC؛ در PR24 سرویس Base پاسخ 429 داده بود.

۲. انتخاب کیف‌پول‌ها فقط با اطلاعات قابل‌دسترسی تا همان روز؛ تعیین خوشه‌های مستقل و محاسبه سود واقعی پس از واریز، برداشت، معاملات باز و انتقال‌ها.

۳. دریافت قیمت قابل‌اجرای واقعی برای سفارش حدود ۲۰ دلار در لحظه‌ای که دنبال‌کننده امکان معامله دارد؛ احتساب تأخیر، تراکنش ناموفق، هزینه و اسلیپیج.

۴. حفظ فرضیات ثابت H1 تا H4 از PR18، ساخت بک‌تست واقعی حساب مشترک ۱۰۰ دلاری، خروج‌ها و بازده هندسی روزانه، مقایسه با نقد/هولد و داده Out-of-Sample دیده‌نشده. هر چهار فرضیه هنوز داده کافی ندارند.

۵. اجرای Paper Trading آینده‌نگر با ثبت سیگنال‌ها و خطاها؛ حداقل ۹۰ روز، و برای H4 حداقل ۱۸۰ روز، بدون تغییر مخفی پارامترها.
