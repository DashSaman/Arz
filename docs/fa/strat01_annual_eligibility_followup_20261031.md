# غربال‌گری مجدد نتایج ۲۰۲۵ با سقف سخت سفارش

تاریخ مبنا: ۳۱ اکتبر ۲۰۲۶. این تحلیل از فایل **موجود** ۱۸۵ ردیفی ساخته شده است و **بک‌تست جدید یا معامله واقعی نیست**.

## نتایج

| متریک | نتیجه |
|---|---:|
| ردیف‌های سالانه (شامل کنترل و نسخه‌های هم‌پوشان) | ۱۸۵ |
| Stress مثبت | ۵۵ |
| Stress منفی | ۱۱۶ |
| بدون تغییر | ۱۴ |
| سقف سفارش با عبارت صریح `pass in both historical simulations` | ۴۶ |
| Stress مثبت **و** سقف صریح معتبر | ۹ |
| موارد بالا **و** حداقل ۱۰ چرخه بسته در هزینه پایه و افت حداکثر ۱۰٪ | **۲** |
| از این دو، عبور از Gate اصلیِ ثبت‌شده در گزارش بومی بعدی | **۰** |
| واجد شرایط Paper Trading | **۰** |

دو موردِ صرفاً پژوهشی:
- **ATR_vol_wall_clock / WETH / 60m**: سال ۲۰۲۵ در Stress **+۴٫۹۳۳۷٪**، تعداد چرخهٔ هزینه پایه **۱۴**، افت هزینه پایه **۲٫۱۱۹۳٪**.
- **ATR_wall_clock / WETH / 60m**: سال ۲۰۲۵ در Stress **+۲٫۶۱۸۳٪**، تعداد چرخهٔ هزینه پایه **۱۷**، افت هزینه پایه **۳٫۳۶۴۸٪**.

برای هر دو، نتیجهٔ `passes_all=False` در [گزارش مستقل بومی](../../reports/strat01/2026-10-31-all-strategies/other/clock_native_gates.csv) وجود دارد. آزمون بومی یک پنجره زمانی **متفاوت** دارد و نباید به‌عنوان همان بازه سالانه تفسیر شود. آن نتیجه برای رد تعمیم سود تاریخی اهمیت دارد، نه به‌عنوان زیان قطعی بازار آینده.

نتیجهٔ مثبت سالانه، مجوز سرمایه‌گذاری نیست. این دو نمونه نیز با سیگنال‌دهی و داده‌های قبلاً مشاهده‌شده غربال شده‌اند. اجرای قابل‌اثبات DEX در زمان سیگنال، هزینه تمام‌شده، استحکام چندرژیمی و پیشروی واقعی هنوز کامل نیست.
