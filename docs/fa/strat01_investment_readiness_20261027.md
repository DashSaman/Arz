## کنترل‌هایی که اضافه شدند

۱. **پوشش زمان و منبع**: فقط فایل‌هایی که واقعاً در `reports/strat01/forward/` به‌شکل یکتای زمان UTC ثبت شده‌اند ارزیابی می‌شوند. زمان داخلی اولین مشاهده و نام فایل نباید اختلاف ناموجه داشته باشند. بازه OOS ثابت `2026-10-27T00:00Z` است و کندلی که هنوز بسته نشده، پذیرفته نمی‌شود.

۲. **بازار مشترک دو دارایی**: هر رکورد باید WETH و cbBTC را با بازه ۴ساعته و هش کندل متناظر داشته باشد. تکرار و اختلاف بین نسخه‌های یک کندل به‌عنوان **تعارض داده** ثبت می‌شود؛ داده گمشده صفر بازده یا قیمت ثابت نمی‌شود.

۳. **ریسک استفاده از Quote**: Quote خواندنی QuoterV2 نباید `executed_order=true` یا `realized_pnl` داشته باشد. BaseFee و L1 Oracle برای طول فرضی تراکنش، سند کارمزد **واقعاً پرداخت‌شده به USD** نیستند؛ نبود L1/L2/Failure/Slippage همچنان UNKNOWN است.

۴. **امتیازدهی شفاف**: تعداد فایل‌ها، تعداد جفت کندل‌های ثبت‌شده، تعداد شکاف‌ها، تعارض‌ها و فهرست موانع برای سرمایه‌گذاری گزارش می‌شود. داده ثبت‌شده توسط GitHub به‌تنهایی لزوماً به معنی احراز مستقل زمان انتشار اولیه ارائه‌دهنده یا اجرای موفق Order نیست؛ این مرز صریحاً حفظ شده است.

۵. **کنترل پیوسته**: Workflow جدید `.github/workflows/strat01-investment-gate.yml` برای هر Push فایل آینده‌نگر به `main` دوباره حسابرسی آفلاین و گزارش Artifact تولید می‌کند؛ نیازی به درخواست شبکه یا ارسال سفارش ندارد.
