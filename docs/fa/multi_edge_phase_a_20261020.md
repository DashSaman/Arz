## پیاده‌سازی

فاز A پروتکل ثابت H1 تا H4 را بدون تغییر قواعد Candidateها به نرم‌افزار قابل آزمون تبدیل کرد. بسته جدید رویدادهای عمومی Wallet را سخت‌گیرانه اعتبارسنجی می‌کند، Cost Basis را با FIFO و Weighted Average بازسازی می‌کند، Profit Score و Copyability Score می‌سازد، Walletهای مرتبط را یک خوشه می‌داند، داده Base RPC و GeckoTerminal را فقط‌خواندنی و محدود دریافت می‌کند، Diagnostic ثابت پنج‌دقیقه‌ای H3 را اجرا می‌کند و کفایت داده را به‌صورت ماشینی می‌سنجد.

هیچ Wallet، Signer، Approval، ارسال تراکنش، API پولی یا سرویس دائمی وجود ندارد. Connector RPC فقط متدهای خواندنی مشخص را مجاز می‌کند. داده خام Provider در Runtime نادیده‌گرفته‌شده باقی ماند و فقط شمارش، Hash و محدودیت‌های مشتق‌شده Commit شدند.

Cost Basis نامعلوم صفر نیست. فروش بیش از Lotهای شناخته‌شده حل‌نشده باقی می‌ماند. Fee شبکه که به واحد Quote نامعلوم باشد، PnL خالص را نامعلوم می‌کند. Labelهای Provider باید Provider، Version و زمان مشاهده داشته باشند و به گذشته Backfill نشوند. Walletهای مرتبط فقط یک رأی Consensus دارند.
