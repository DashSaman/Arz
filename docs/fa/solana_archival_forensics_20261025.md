## چه تغییری در پروژه ایجاد شد؟

موتور آرشیو می‌تواند ردیف‌های JSONL تولیدشده توسط گردآورنده Solana موجود Arz را بخواند؛ بدون اتصال شبکه. برای هر تراکنش، هش SHA-256 فایل/پاسخ، امضا، Slot، زمان، وضعیت اجرا، امضاکنندگان، آدرس اول به‌عنوان پرداخت‌کننده کارمزد، تغییر خالص Lamport و تغییر دقیق حساب‌های توکنِ متعلق به آدرس بررسی می‌شود.

**فرق مهم:** وجود آدرس در `getSignaturesForAddress` با امضاکردن، پرداخت کارمزد یا مالکیت اقتصادی تراکنش یکسان نیست. بنابراین تغییر توکن‌ها به‌طور خودکار Swap و سود محسوب نمی‌شود. بدون تأیید مسیر برنامه DEX، هزینه تمام‌شده تاریخی FIFO، ارزش‌گذاری دلاری زمان اجرا، واریز/برداشت و موجودی روزانه، فیلد سود `null` می‌ماند.

تست‌ها نیز ثابت می‌کنند که داده تکراری، ترتیب اشتباه Slot، امضای ناسازگار، وضعیت شکست متناقض، مالک توکن نامشخص، پرداخت‌کننده کارمزد شخص ثالث و دریافت ظاهری USDC نمی‌توانند به یک سود حسابرسی‌شده تبدیل شوند. نمونه‌های آموزشی مصنوعی‌اند؛ اجرای دوباره ۱۰ تراکنش قبلی صرفاً روی گزارش مشتق‌شده آن‌ها انجام شده و به معنای دریافت دوباره اصل تراکنش نیست.

## نتایج واقعی داده

بررسی قبلی PR #29: از ۱۶۰ رکورد فهرست امضا برای Cented/Decu، فقط ۱۰ جزئیات تراکنش قابل خواندن بود؛ در هر ده مورد Cented معامله زنجیره‌ای ناموفق بود و آدرس Cented امضاکننده یا پرداخت‌کننده کارمزد نبود. درخواست جزئیات Decu با HTTP 429 متوقف شد. موتور جدید **هیچ سودی** از این ده مورد استخراج نکرد.

### تلاش برای منبع آرشیوی رایگان

`solarchive.org` روی سایت عمومی خود Parquet و مجوز CC-BY-4.0 را معرفی می‌کند. تاریخچه منتشرشدهٔ قابل مشاهده آن در وب‌سایت برای ماه‌های موردنیاز **۲۰۲۶** کامل نیست؛ در اجرای واقعی GitHub Actions سه آدرس زیر **HTTP 404** دادند:

- `https://data.solarchive.org/txs/index.json`
- `https://data.solarchive.org/txs/2025-12-05/index.json`
- `https://data.solarchive.org/txs/2026-10-24/index.json`

در نتیجه **هیچ Parquet و هیچ تراکنش تازه‌ای** از این منبع دانلود نشد. نه دسترسی آن را اثبات می‌کنیم و نه از 404 نتیجه می‌گیریم که کل پروژه آرشیو وجود ندارد. تنها نتیجه این است که این مسیرها برای این اجرای ما قابل استفاده نبودند.

## اجرای مجدد

```bash
PYTHONPATH=src:. python -m unittest discover -s tests -p 'test_solana_archival_forensics.py' -v
PYTHONPATH=src:. python scripts/solana_archival_forensics.py --saved-probe reports/onchain_2026-10-25/wallet_pagination_rpc_observed.json --output /tmp/arz-unique-role-audit.json
```

برای فایل آرشیوی قانونی JSONL با ساختار `{wallet, signature, signature_meta, rpc_transaction}`:

