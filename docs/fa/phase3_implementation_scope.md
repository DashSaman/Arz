# دامنهٔ محدود پیاده‌سازی فاز ۳

ادامهٔ پیش‌ثبت 1fa32de بدون تغییر استراتژی‌ها و نتایج قبلی. فقط یک دور: بررسی ریشه‌ای داده؛ کنترل جداگانهٔ پذیرش شواهد مظنهٔ تاریخی؛ محاسبهٔ هزینهٔ رسید متناسب با شبکه؛ سه قاعدهٔ ثابت قبلی و یک مومنتوم تطبیقی پیش‌ثبت‌شده. تمام کار بدون کیف‌پول است. اعتبارسنجی ساختار مظنه، اثبات زنجیره یا گواهی سرمایه‌گذاری نیست. بدون شاهد دقیقِ مبلغ، متصل به هش و بازپخش مستقل، بازدهٔ تأییدشدهٔ اجرایی null می‌ماند و سود کندلی تأیید نمی‌شود.

بازهٔ ۱ ژوئیهٔ ۲۰۲۱ تا ابتدای ۱ ژانویهٔ ۲۰۲۲، انتقال تاریخی به گذشته است، نه آزمون زمانی آینده‌نگر. حداقل ۷۲ کندل آماده‌سازی رعایت می‌شود؛ اجرای روزانهٔ فاقد پوشش حذف می‌شود و قیمت غایب تولید نمی‌شود. جدول سقف/هزینهٔ ثابت، توصیفی است و بهینه‌سازی یا انتخاب دوباره نیست. حالت‌های اضافی شامل نه تنش مشخص اجرا با سقف ۵، پنجرهٔ توصیفی ۱۸۰روزهٔ هم‌پوشان، چهار آستانهٔ برداشت در چهارساعته و خریدونگهداری با هزینهٔ مقایسه‌پذیر است. حداکثر ۷۰۰ شبیه‌سازی و ۲۵۰ مگابایت پاسخ منابع. تاریخچهٔ دقیقه‌ای ساخته نمی‌شود و خروجی‌های دیده‌شدهٔ ۳۶۵/۷۳۰روزه به‌عنوان OOS تازه تکرار نمی‌شوند.

آزمون‌های مصنوعی پیش از ماژول جدید نوشته و محلی اجرا می‌شوند؛ سپس کل مجموعهٔ قبلی و جدید روی مخزن واقعی در GitHub Actions اجرا می‌شود. فقط اجراگر عمومی موقت استفاده می‌شود؛ سرویس پایدار یا paper راه‌اندازی نمی‌شود. شکست دریافت منابع حفظ می‌شود. انتشار خروجی‌های مشتق‌شده با ابزار انتشار موجود، عمداً محدود به شاخهٔ پژوهشی تازه انجام می‌شود. main یا شاخه‌های دیگر بازنویسی نمی‌شوند. ۶۹۰ خروجی قبلی و کد اولیه بدون تغییر باقی می‌مانند.

کلون مستقیم در محیط چت خطای DNS داشت. تلاش کلون روی دستگاه متصل توسط ابزار مسدود شد و روی آن دستگاه تکرار نشد. بنابراین مسیر اجرا، آزمون محلی ماژول مستقل و GitHub Actions خود مخزن است، نه اجرای کد روی دستگاه کاربر.
