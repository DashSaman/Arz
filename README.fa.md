Arz سامانه‌ای پژوهشی، قابل اجرا و بدون کیف‌پول است که بررسی می‌کند آیا استراتژی‌های نقدیِ بدون اهرم، با سرمایهٔ کوچک و پس از هزینه‌ها مزیت دارند. کد مستقل Python، آزمایش‌های تاریخی واقعی، منابع، بازبینی مستقل کد و مستندات هم‌ارز فارسی و انگلیسی در این مخزن ثبت شده‌اند. **هیچ استراتژی برای دریافت سرمایهٔ واقعی تأیید نشده است.** تکمیل نرم‌افزار یا سود تاریخی، اثبات درآمد آینده یا مجوز معامله نیست.

## یافته‌های فعلی

سه استراتژی ثابت پیش از نخستین اجرای عملکرد روی بازار پیش‌ثبت شدند. آزمایش از ۹۹۹ کندل کامل چهارساعتهٔ یک استخر WETH/USDC روی Base، با پوشش ۱۶۶٫۵ روز استفاده می‌کند. ۲۴ اجرا شامل توسعه، پنجره‌های زمانی رو‌به‌جلو، آزمون نهایی کنارگذاشته‌شده و تنش هزینه است. هر پنجرهٔ رو‌به‌جلو از حساب مجازی تازهٔ ۱۰۰دلاری آغاز می‌شود؛ این خروجی، پرتفوی پیوسته با رشد مرکب نیست.

| آزمون نهایی: ۹ سپتامبر ساعت ۱۶ تا ۱۳ اکتبر ساعت صفر، UTC | بازده خالص | معاملات بسته | بازده با دوبرابر هزینهٔ مدل |
|---|---:|---:|---:|
| دنبال‌کردن روند | ‎−۲٫۴۴۴۳٪ | ۶ | ‎−۲٫۹۱۸۳٪ |

| بازگشت به میانگین | ‎+۰٫۱۴۲۷٪ | ۴ | ‎−۰٫۱۷۷۷٪ |

این نتایج شبیه‌سازی مربوط به پنجره‌ای حدوداً ۳۳روزه‌اند. فاصلهٔ عدم‌قطعیت bootstrap مشروط برای میانگین بازده هر سه حالت پایه، صفر را در بر می‌گیرد. هزینه‌ها با قیمت اجرایی واقعی کالیبره نشده‌اند، تعداد معاملات کافی نیست و عملکرد آینده‌نگر تأیید نشده است. سود کوچک بازگشت به میانگین با دوبرابرشدن هزینه از بین می‌رود. [ارزیابی کامل](docs/fa/strategy_evaluation.md)، [جدول نتایج](reports/backtests/summary.csv)، [منشأ داده و اجرا](reports/backtests/manifest.json).

با بازده خالص ماهانهٔ **فرضی** ۲٪، درآمد ۱۰۰ دلار در ماه به ۵۰۰۰ دلار سرمایه نیاز دارد. سرمایهٔ ۱۰۰دلاری با بازده مؤثر سالانهٔ ۳ تا ۵٪، پیش از هزینه حدود ۰٫۲۵ تا ۰٫۴۱ دلار در ماه می‌سازد. این‌ها سناریوی ریاضی هستند، نه پیش‌بینی. [امکان‌پذیری اقتصادی](docs/fa/economics.md).

## پوشش پژوهش

- ده مدخل موتور/ماژول از نه مخزن: Freqtrade، FreqAI، freqtrade-strategies، Hummingbot، Gateway، OctoBot، Jesse، LEAN، NautilusTrader و trade-executor. آمار تاریخ‌دار، مجوز و نسخه‌ها در [projects.csv](research/projects.csv) و [manifest بالادستی](upstreams/manifest.json) ثبت شده‌اند.
- هشت صرافی AMM/تجمیع‌گر، به‌علاوهٔ بررسی جداگانهٔ نه محصول Hyperliquid، چهار شبکه و یازده مدل دیفای. [فهرست صرافی‌ها](research/venue_index.csv) جدول‌ها را به هم مرتبط می‌کند.
- اجتماع حفظ‌شدهٔ ۱۹۰ رکورد منبع، ۲۷ رکورد دسترسی و ۵۸ مشاهدهٔ امنیتی یا ریسک بالادستی/پروتکل. URL تکراری، رخداد تاریخی و شرط دسترسی، حسابرسی مستقل یا آسیب‌پذیری تازه محسوب نمی‌شوند. [راهنمای منابع](research/README.md).
- محدودیت رسمی رابط، API، پروتکل، زیرساخت و ناشر استیبل‌کوین جدا بررسی شده است. تابعیت ایرانی، اقامت و IP سه پرسش جدا هستند. ممنوعیت صریح، خدمتِ تحت پوشش را مسدود می‌کند و موارد مبهم در انتظار بررسی می‌مانند. طراحی دورزدن محدودیت ارائه نشده است.

هیچ ربات بالادستی کپی، فعال یا فورک نشده است؛ آزمایش فعلی ضرورت این یکپارچه‌سازی را نشان نداده است. Gateway گزینهٔ مشروط اتصال DEX در آینده باقی می‌ماند. AI تا اثبات مستقل مزیت افزوده نسبت به قواعد ساده وارد MVP نشده است.

## اجرای سامانهٔ آزمایشی

Python نسخهٔ ۳٫۱۱ یا جدیدتر، Git و محیط shell لازم است. هسته وابستگی اجرایی شخص ثالث ندارد. نصب و آزمون آفلاین دادهٔ بازار دریافت نمی‌کنند.

```bash
git clone https://github.com/DashSaman/Arz.git
cd Arz
bash scripts/install.sh
PYTHONPATH=src .venv/bin/python scripts/verify_repository.py
PYTHONPATH=src .venv/bin/python -m arz --help
```

[راهنمای اجرا](docs/fa/operations.md) دریافت داده، بازپخش تاریخی، مشاهدهٔ مجازی محدود و برخورد با خطا را توضیح می‌دهد. دادهٔ خام OHLCV تا روشن‌شدن مجوز نگهداری و بازنشر در Git قرار نگرفته است. بازتولید دقیق آزمایش بازار به ورودیِ مجاز با هش منتشرشده نیاز دارد. کد و آزمون مصنوعی مستقیماً قابل بازتولیدند؛ بازتولید مستقلِ دقیق نتیجهٔ بازار هنوز در انتظار تکمیل است.
