# Upstream manifest / فهرست بالادستی

`manifest.json` captures official repositories, licenses, versions, exact commit heads and inspection evidence. Arz's original source is MIT. No upstream runtime was imported, vendored, forked or activated. Candidate integrations remain optional and conditional; a repository reference is not a security or performance endorsement. Preserve upstream licenses and inspect pinned source/deployment before any future integration. Source IDs in each report/registry are scoped locally; the combined registry uses scope prefixes to avoid collisions.

این فهرست مخازن رسمی، مجوزها، نسخه و Commit دقیق و شواهد بررسی را ثبت می‌کند. کد Arz تحت MIT است و کد بالادستی کپی، فورک، وارد یا فعال نشده است. هر اتصال آینده به بررسی مجوز و امنیت نیاز دارد. معرفی مخزن تأیید سودآوری نیست. شناسه منابع در هر گزارش محلی است و فهرست تجمیعی برای جلوگیری از تداخل پیشوند دارد.
