# Arz — DEX Trading & DeFi Research

**Experimental Trading Capital: Maximum $100**

**Mode: Research / Simulation Only**  
**Live Trading Authorization: DISABLED**  
**Research started: 2026-10-13 (UTC)**

Arz investigates whether transparent, reproducible, non-leveraged trading or DeFi strategies are economically feasible at small scale. No profitable strategy is established and no live financial action is authorized.

The first repository inspection found an empty public repository, no commits, no branches, no issues, and no pull requests. This commit establishes the project record. Research, implementation, evidence matrices, and equivalent Persian/English documentation are being developed from this baseline.

## Non-negotiable boundaries

- No live transaction signing, token approvals, deposits, transfers, borrowing, leverage, martingale, paid services, or automatic replenishment.
- Never store wallet keys, seed phrases, private financial information, or credentials in this repository.
- Distinguish software tests, historical backtests, live paper observations, and real trading evidence.
- Check official access restrictions independently; a permissionless contract does not imply an unrestricted interface, API, RPC, or stablecoin issuer.
- A future GO finding would mean readiness to request a separately authorized limited pilot, not authorization to trade.
