## شواهد واقعی موجود قبل از این مأموریت

- هویت دو استخر Uniswap V3 روی Base و کارمزد ۵۰۰ قسمت در میلیون (تقریباً ۵ واحد پایه در ده‌هزار) قبلاً روی بلاک‌چین بررسی شده بود. این فقط برای همان استخرهاست و مسیرهای جدید Aggregator را تأیید نمی‌کند.
- فاصلهٔ فرضی رفت‌وبرگشت Quote یک‌بلاکی بدون گس برای اندازهٔ ۲۰ USDC، حدود ۰٫۰۲۰۰۱۵ دلار WETH و ۰٫۰۲۰۶۲۹ دلار cbBTC ثبت شده بود. این اعداد قیمت اجرای سیگنال با تأخیر ۶۰ ثانیه یا معاملهٔ واقعی نیستند.
- نمونهٔ Oracle گس برای اندازهٔ فرضی تراکنش و مصرف فرضی L2، بازهٔ سناریویی ۰٫۰۰۱۱۶ تا ۰٫۰۰۴۰۶ دلار را نشان می‌دهد، نه گس واقعاً پرداخت‌شده.
- درخواست قبلی خواندن رسید عمومی با HTTP 429 متوقف شد. هیچ رسید معتبر به دست نیامد و تکرار یا تعویض میزبان برای دورزدن محدودیت انجام نشد.

## قرارداد تحویل به تیم Quant

فایل src/arz/execution_costs.py قابل import است. توابع hypothetical_roundtrip و account_scenario فقط برای سناریوهای پژوهشی و کل حساب مناسب‌اند، نه OOS واقعی. quote_roundtrip برای خرید و فروش نامنطبق یا زمان‌بندی غیرعلّی خطا می‌دهد، و بدون هر دو هزینهٔ واقعی یا صریح، بازده خالص را null می‌گذارد. flag تأیید کامل اجرا در این نسخه هرگز true نمی‌شود. توابع بدون شبکه و بدون کیف‌پول هستند. دستورهای بازتولید و توضیحات دقیق در README انگلیسی همین پوشه ثبت شده است.
